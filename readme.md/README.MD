# Developer Portfolio - Godwin Bulus Kambai

A modern, responsive, and customizable personal developer portfolio built with semantic **HTML5**, custom **CSS3**, and interactive **JavaScript**. Features dark/light mode toggle, dynamic project filtering, interactive skill progress bars, and a responsive contact form.

---

## 🚀 Live Demo

- **GitHub Pages / Live Site:** [https://your-username.github.io/portfolio](https://your-username.github.io/portfolio)

---

## ✨ Features

- 🌓 **Dark / Light Mode:** Automatic system preference detection with persistent state saved in `localStorage`.
- 📱 **Fully Responsive Layout:** Designed mobile-first, looking sharp on phones, tablets, and desktop displays.
- 🎯 **Filterable Projects Gallery:** Seamless dynamic filtering by category (*All*, *Web Apps*, *Design & Arch*).
- 📊 **Skill Progress Visualization:** Modern progress bars displaying proficiency across key technical stack areas.
- 📬 **Contact Form Interface:** Client-side validation with dynamic form status feedback.
- 🔗 **Social Media Integration:** Quick-access links to LinkedIn, GitHub, Facebook, and Email.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure for strong accessibility and SEO.
- **CSS3:** Custom CSS with CSS variables, Flexbox, Grid, smooth transitions, and custom scrollbars.
- **JavaScript (ES6+):** Vanilla DOM manipulation for dark mode toggle, filtering, and form submission logic.
- **FontAwesome 6:** Clean vector icons for social media links, skill badges, and UI elements.
